Grids (lat/lon/z)

Horizontal Grid

MIMAS uses a regular latitude–longitude grid on a spherical Earth. The longitude grid is uniform. The latitude grid is explicitly constructed as a fixed array.

Parameter Value Description
Longitude Resolution 3° 120 longitudes: 0°, 3°, …, 357°
Latitude Resolution 1° 53 latitudes: 37.5°N, 38.5°N, …, 89.5°N
Grid Type Lat–Lon (regular) dx varies with latitude via cos(latitude); dy is constant in meters for 1°

Vertical Grid

The vertical grid is defined on geometric altitude with constant spacing.

Parameter Value Description
Vertical Levels 163 Indexed k = 1 … 163
Vertical Coordinate Geometric altitude (km) zgeo(k) = 77.8 + 0.1·(k−1) km
Top Boundary 94.0 km Bottom at 77.8 km; Δz = 0.1 km (100 m)

Time Stepping

Temporal Framework

The transport time step in the Fortran is set to 90 seconds (dttrans). Several processes run on effective multiples of this (e.g., diffusion uses dttrans_2 = 2·dttrans).

Parameter Value Description
Transport time step 90 s Base step used in CFL checks and advection
Derived time step 180 s Used in vertical diffusion as dttrans_2 (2·dttrans)
Scheme Type Split by process Eulerian transport (grid fields) + Lagrangian particle loop
Conservation Process-dependent H₂O is advected as a mixing ratio using a monotonic advection scheme; particles are tracked individually

Data Sources

External Dynamics Forcing (u, v, w, T, ρ)

Background meteorology is provided as gridded 3-D fields on the MIMAS grid (wind components, temperature, density, and a height/vertical reference field). In the code this appears as arrays such as um, vm, wm, tm, dm, zm, with time levels blended (e.g., um = a1·um1 + a2·um2) in the flow logic.

  • Grid: nbneu × igitneu × kgitneu (53 × 120 × 163)
  • Typical fields: u, v, w, T, density (ρ), and z-related field
  • Used to drive: Eulerian H₂O transport + particle background conditions

Solar Forcing Input (Lyman-α series)

Photolysis uses an observed Lyman-α time series (xlyman_obs) as input. The photodissociation cross section for H₂O is set as a constant in the photolysis routine.

  • Input: xlyman_obs(366) (daily series)
  • Used by: sub_photolyse
  • Role: removes H₂O via photodissociation in sunlit conditions

Background Fields

Background fields are externally provided meteorological state variables on the fixed MIMAS grid. They are treated as forcing for transport and microphysics (i.e., they provide the environment), and are used for both Eulerian and Lagrangian parts of the model.

Field Source Update Frequency
Temperature (tm) External forcing files (read into tm1/tm2 and blended) Time-interpolated between forcing snapshots
Wind (u, v, w) (um, vm, wm) External forcing files (read into *_1/*_2 and blended) Time-interpolated between forcing snapshots
Density (dm) External forcing files Time-interpolated between forcing snapshots
Vertical reference (zm) External forcing files Time-interpolated between forcing snapshots

Tracer Fields

Tracer fields are prognostic quantities evolved by the model. In the current Fortran structure, the key Eulerian tracer is the 3-D H₂O field (hm), which is transported on the grid. The advection implementation treats the transported scalar explicitly as a mixing ratio.

Tracer Description Units
H₂O (hm) Water vapor field (Eulerian grid tracer) Mixing ratio (dimensionless; transported as mixing ratio)
Ice on particles Not a grid tracer: tracked on Lagrangian particles (radius/mass per particle) Particle-property (per particle), not a grid field
Dust nuclei on particles Particle ensemble carries dust nuclei that may activate for ice growth Particle-property (per particle), not a grid field

Particle Ensemble

MIMAS uses a Lagrangian particle ensemble to represent dust nuclei and ice particles. Particle positions are mapped to the Eulerian grid each step (i=int(xfeld), j=int(yfeld), k=int(zfeld)) to sample background conditions (tm, dm, and hm).

  • Number of particles: ≈ 40 million (as documented in the model flow extraction)
  • Particle properties: position (x,y,z), radius/state variables (e.g., rfeld), and dust/ice bookkeeping
  • Initialization: dust size distribution is initialized in discrete radius classes (see dust init routine structure)
  • Scientific note: using the same Kz for Eulerian H₂O diffusion and particle random-walk transport is justified in Berger et al. (2002) (cite in Publications page)

Architecture Diagram

Architecture sketch (code-faithful)

Eulerian (grid) side: Grid: lat (53) × lon (120) × z (163) Fields: hm (H2O mixing ratio), plus forcing: um,vm,wm,tm,dm,zm Steps: advection (Walcek) + vertical diffusion (Kzz) + photolysis Lagrangian (particle) side: Particle ensemble (~1.40e6) Each step: map particle -> grid cell -> read (tm, dm, hm) -> microphysics update

This diagram is intentionally minimal: it separates (1) grid tracers and forcing fields from (2) particle-state evolution.
